## 💻 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

---

### Installation

Clone the repository:

```bash
git clone https://github.com/myself-meen/maga-tech-website.git
````

Navigate into the project directory:

```bash
cd maga-tech-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🧠 Lessons Learned

Building this project helped me strengthen my understanding of modern frontend development and responsive web design using React and Tailwind CSS.

One of the biggest things I learned was adopting a **mobile-first workflow** while designing layouts. Instead of designing for desktop first and fixing responsiveness later, I learned how to structure components for smaller screens first and progressively enhance them using Tailwind’s responsive utility classes.

I also improved my understanding of:

* reusable React component architecture
* responsive navigation design
* flexbox and layout management
* sticky positioning
* deployment workflows
* Git branching and version control

A major challenge during development was deployment configuration using Vite. I encountered issues like blank-page deployments and asset path problems, which helped me better understand production builds, build directories, and deployment pipelines.

This project also gave me hands-on experience converting UI ideas into responsive interfaces while maintaining cleaner and more scalable code using Tailwind CSS utilities.
